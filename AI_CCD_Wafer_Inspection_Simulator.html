Trigger and AI logic

Per-wafer decision

Trigger request: A random machine-side trigger request is generated using the selected probability (default 50%). If there is no request, the CCD normally skips that wafer.

Defect override: A separate simulated upstream warning can force an image capture even when the normal trigger request is absent. This represents an independent sensor/interlock—not AI detecting a defect without an image.

AI inspection: After capture, the external AI model examines the generated image and classifies the robot pad as normal or abnormal.

Important: AI cannot inspect a camera image that was never captured. In a real system, use a machine signal or independent sensor to request/force capture; then run image-based AI on the captured image.
